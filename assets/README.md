# MindTrace Demo Assets

This directory is reserved for future manually captured demo materials.

Do not commit real user data, API keys, `.env.local`, cookies, tokens, full prompts, raw Gemini output, Playwright traces, or screenshots that expose private content.

Current subdirectories:

- `screenshots/`: planned manual screenshots listed in `docs/SCREENSHOT_PLAN.md`.
- `video/`: planned manual recordings and exports based on `docs/VIDEO_SCRIPT.md`.

No fake screenshots or fake videos should be added.
