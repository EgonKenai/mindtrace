# Video Assets

Place future manually recorded demo videos here after reviewing `docs/VIDEO_SCRIPT.md`.

Allowed:

- Local demo recordings using fictional users and Firebase Emulator.
- Recordings that show Fake Provider or mocked AI responses only.
- Edited videos that remove terminal secrets, browser devtools tokens, and private content.

Not allowed:

- Real Gemini request recordings unless separately approved and sanitized.
- Real user journal data.
- API keys, tokens, cookies, `.env.local`, full prompts, raw Gemini output, or provider errors.
- Claims that the project is deployed, commercialized, or a medical product.
