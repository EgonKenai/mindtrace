# Screenshot Assets

Place future manually captured screenshots here after reviewing `docs/SCREENSHOT_PLAN.md`.

Allowed:

- Fictional demo data from Firebase Emulator.
- App UI screenshots that do not expose secrets or real user content.
- 360px, 768px, and 1280px viewport captures.

Not allowed:

- Fake generated screenshots.
- Real user journal content.
- API keys, tokens, cookies, `.env.local`, full prompts, raw Gemini output, or provider errors.
- Playwright traces or reports that may contain page data.
